# Python Range Example

This is a basic Python script that demonstrates how to use a `for` loop with the `range()` function.

## 📄 Code

```python
for i in range(1, 10):
    print(i)

This script prints numbers from 1 to 9 (inclusive of 1, exclusive of 10) using Python's built-in range() function.

▶️ How to Run
Make sure you have Python installed.

Save the code in a file named main.py.

Run the script using the terminal or command prompt:
